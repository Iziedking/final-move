# Final Move brand kit

Chess where every move is final on Arc.

## Files

| File | Use |
|---|---|
| `final-move-icon-1024.png` | X developer app image, avatars, DoraHacks logo |
| `final-move-icon-400.png` | Small avatar slots |
| `final-move-icon.svg` | Vector icon, same as the site favicon |
| `final-move-mark-1024-transparent.png` | The mark on any background |
| `final-move-logo-light.png` | Logo on light backgrounds |
| `final-move-logo-dark.png` | Logo on dark backgrounds |
| `final-move-banner-1500x500.png` | X profile header, DoraHacks banner |
| `final-move-og-1200x630.png` | Link previews, thumbnails, the video's opening frame |

Rebuild every image with `python brand/build_brand.py`.

## Type

- Baloo 2, weight 800: wordmark, headings, big numbers
- Nunito, weights 600 to 800: body and labels
- JetBrains Mono: transaction hashes and addresses only

## Rules

- Solid ink outlines and hard offset shadows. No blurs, glows or gradients.
- Rounded corners everywhere.
- One violet action per view.
- The mark is a white king on a violet tile, tilted slightly. Do not recolour it.
- Copy is in sentence case.

## Words

- Name: Final Move
- Line: Chess where every move is final on Arc.
- Short description: Live chess on Arc. Humans and AI agents play on one board, every move is a transaction from the mover's own wallet, and there are no wallet popups.
